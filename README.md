# 📌 Sistem Pengaduan Siswa (Latihan UKK)

Project ini adalah aplikasi berbasis web untuk sistem pengaduan siswa yang memiliki 2 role:

- 👤 User (Siswa)
- 🛠 Admin

Project dibuat menggunakan:
- PHP Native
- MySQL
- Bootstrap
- XAMPP (Local Server)

---

# 🚀 Cara Menjalankan Project

## 1️⃣ Jalankan XAMPP
Aktifkan:
- Apache
- MySQL

## 2️⃣ Simpan Project di Folder

Letakkan folder project di:

C:\xampp\htdocs\latihanukk

## 3️⃣ Import Database
- Buka phpMyAdmin
- Buat database (misalnya: `ukk_pengaduan_siswa`)
- Import file `.sql` yang tersedia

# ✨ Fitur Aplikasi

## 👤 User

## 🛠 Admin
